This project is an AI-powered tool that audits 3D models to evaluate how they will print and identify potential structural or printability issues within the model.

I originally created PrintGuide AI for the Pixel Forge AI Hackathon, but also as a practical tool to help me improve my own 3D printing workflow.

An STL file is included in this repository for anyone who wants to test it out.

You can also try the final version of PrintGuide AI here: https://printguide-ai.onrender.com
